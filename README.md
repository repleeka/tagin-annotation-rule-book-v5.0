# Tagin Annotation Rule Book v5.0

This repository contains the official **Tagin Annotation Rule Book (Edition 5.0)** and related linguistic resources for the Tani Corpus.

## Contents

1. **`tagin_annotation_book.pdf`**: The primary document outlining the comprehensive annotation guidelines, orthography, and sound system for the Tagin language (Modified Roman Script for Tagin - MRST). It also covers Tagin-Galo correspondences. Edited by Tungon Dugi (ai4arunachal).
2. **`SPELLING_GUIDE.md`**: A detailed spelling and pronunciation guide for the languages featured in the Tani corpus (`tani_corpus.json`). It provides IPA values, examples, and orthographic conventions for:
   - Tagin (`tgj_Latn`)
   - Galo (`adl_Latn`)
   - Nyishi (`njz_Latn`)
   - Apatani (`apt_Latn`)
   - Adi (`adi_Latn`)
   - Mising (`mrg_Latn`)
   - Hruso / Aka (`hru_Latn`) - A non-Tani language included in the corpus

## About the Tagin Annotation Rule Book

The rule book establishes standard conventions for spelling, grammar annotation, and handling of loanwords, punctuation, and compound words in Tagin. It is the foundational guide used for projects like the Tagin Bible and GinLish.

## How to Use

- For the complete set of annotation rules, consult the **PDF**.
- If you are working with the `tani_corpus.json` data and need a quick reference for how sounds map to letters across different Tani languages, refer to the **Spelling Guide**.
